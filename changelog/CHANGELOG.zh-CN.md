# 变更日志 [English](CHANGELOG.md)

本项目的所有重要变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
并且本项目遵循 [语义化版本](https://semver.org/spec/v2.0.0.html)。

## [v0.0.13] - 2026-08-07

### 新增
- 新增云函数 `ctx.cloud` 统一资源门面，支持应用数据库、对象存储及公共函数调用。
- 新增运行时日志流、函数异常捕获及控制台实时日志展示。
- 新增数据库集合索引管理、存储与数据库完整操作界面。
- 新增生产级 GitHub Actions 发布流程，构建并推送 `linux/amd64` 与 `linux/arm64` 镜像，并在发布前执行真实 Chrome 冒烟测试。

### 修复
- 修复函数编辑器草稿、布局状态、Python 格式化及 Monaco 本地化资源加载问题。
- 修复应用运行时生命周期、任务恢复、容器状态观测和删除重试等可靠性问题。
- 修复本地 HTTPS 开发环境登录、数据库索引读取和 LSP 依赖健康检查问题。
- 修复 GitHub Actions 在 tag checkout 后误判 annotated tag 的发布门禁问题。
- 修复生产冒烟测试创建匿名 Playwright 页面时误用 owner context 的问题。
- 加固用户会话、函数鉴权、运行时凭据隔离、动态 CORS 和对象存储权限边界。

### 重构
- 将服务端数据库驱动从 Motor 迁移到 PyMongo Async，并补充 Beanie 2 兼容层。
- 重构函数执行器、任务 worker、运行时控制面和应用存储管理。
- 完成 Pydantic V2 配置迁移，统一 Python 项目的冻结依赖与生产镜像构建来源。
- 重构云资源、数据库、函数、日志和应用页面的交互与视觉布局。

### 文档
- 新增中英文文档站、部署指南、开发指南和用户操作文档。
- 完善生产部署、版本发布、Docker Hub 配置及 LSP sidecar 镜像复用说明。

## [v0.0.12] - 2026-05-10

### 新增
- 新增兼容 RustFS 的 S3 存储能力及相关上下文处理。
- 新增基于 sidecar 的运行时 LSP 链路，并接入 Pyright 编辑器智能能力。
- 新增云函数 Monaco Editor 支持及 LSP 冒烟测试辅助能力。

### 修复
- 修复前端与运行时 LSP 的初始化、格式化和回退行为问题。
- 修复数据库页面刷新、删除、编辑响应问题，并改进 S3 错误处理。
- 修复密码哈希安全问题以及若干前端字段问题。

### 重构
- 在服务端与应用端全面用兼容 RustFS 的存储实现替换 MinIO 集成。
- 重构前端函数编辑与应用页面，并刷新登录页、首页、应用页界面。

### 其他
- 同步纳入 `dev-0.0.8` 到 `dev-0.0.11` 的历史变更记录。
- 清理 lint 问题，更新忽略规则，并对齐相关项目配置。
